# pulse-forge — Agent Guide

Multi-tenant feature flag evaluation engine + event-analytics API with an embedded admin dashboard. Next.js 15 + Hono 4 on Vercel Edge Runtime, Neon Serverless Postgres + Drizzle ORM.

---

## Commands

| Command                    | What it does                                        |
| -------------------------- | --------------------------------------------------- |
| `npm run dev`              | Start dev server (Next.js)                          |
| `npm run build`            | Production build                                    |
| `npm run start`            | Start production server                             |
| `npm run check`            | `lint` + `typecheck` (run before push)              |
| `npm run lint`             | ESLint flat config                                  |
| `npm run format`           | Prettier                                            |
| `npm run typecheck`        | `tsc --noEmit`                                      |
| `npm run db:generate`      | Drizzle Kit: generate migration from schema changes |
| `npm run db:migrate`       | Apply pending migrations                            |
| `npm run db:push`          | Push schema directly (dev only, no migration file)  |
| `npm run db:studio`        | Drizzle Kit: open database studio                   |
| `npm run db:seed`          | Seed DB with sample tenant/user/flags               |
| `npm run test:unit`        | Vitest unit tests                                   |
| `npm run test:integration` | Vitest integration tests (require DB)               |
| `npm run test:e2e`         | Playwright E2E (requires `build` + running server)  |

**CI order** (`.github/workflows/ci.yml`): `prettier --check` → `lint` → `typecheck` → `db:migrate` → `test:integration` → `build` → `test:e2e`.

**Pre-push** runs `typecheck`. **Pre-commit** runs `lint-staged` (ESLint fix + Prettier on staged files).

## Architecture

- **Hono API** lives in `src/lib/hono-app.ts`, mounted on edge runtime via `hono/vercel` `handle()` in `src/app/api/[[...route]]/route.ts`.
- **Server actions** (`'use server'`) in `src/app/actions/flags.ts` handle CRUD mutations from the dashboard.
- **Dashboard pages** under `src/app/dashboard/[tenantSlug]/` — server-rendered, tenant-scoped.
- **DB driver** (`src/db/index.ts`) switches dynamically: `pg` (Node native) for local/CLI, `@neondatabase/serverless` (WebSockets) for edge runtime. Detection via `NEXT_RUNTIME` and URL check.
- **Evaluation engine** (`src/lib/evaluator.ts`): djb2 hashing for deterministic rollout %, 8 condition operators.
- **Typed RPC client** (`src/lib/rpc.ts`): `hc()` from `hono/client`, auto-injects Bearer token server-side.

## Testing

- **Integration tests** (`tests/integration/`) need a running Postgres with migrations applied. They use `DATABASE_URL` from the environment. Run with `npm run test:integration`.
- **E2E tests** (`tests/e2e/`) need `npm run build` first, then Playwright starts the server automatically in CI. Run locally with `npm run test:e2e`.
- **Vitest config** (`vite.config.ts`): `fileParallelism: false`, loads env via `@next/env`.
- **Playwright config** (`playwright.config.ts`): Chromium only, 2 retries in CI, 1 worker in CI.

## Database

- **Schema** in `src/db/schema.ts`: 4 tables — `tenants`, `users`, `feature_flags`, `analytics_events`.
- **Enum**: `flag_type = 'boolean' | 'multivariate'`.
- **Unique constraint**: `(tenant_id, key, environment)` on feature flags.
- **Migrations** in `drizzle/` — generated by `drizzle-kit`. Only one migration exists (`0000_funny_drax`).
- **Seed script** (`src/db/seed.ts`): creates a tenant, user, boolean flag, and multivariate flag.

## Edge Runtime Notes

The API runs on Vercel Edge Runtime. `next.config.ts` excludes Node.js-specific database modules (`pg`, `pg-native`, `pg-connection-string`, `pgpass`, `drizzle-orm/node-postgres`) via webpack `IgnorePlugin` when `nextRuntime === 'edge'`.

**Never import Node-only modules in `src/lib/hono-app.ts` or `src/db/index.ts` without adding them to the ignore list in `next.config.ts`.**

## Conventions

- **Nordic theme** (dark/arctic palette) via Tailwind — see `tailwind.config.ts` for custom colors, animations, shadows.
- **Format**: single quotes, semicolons, trailing commas, 100 print width, 2-space indent.
- **No unused vars** (`@typescript-eslint/no-unused-vars: ['warn', { argsIgnorePattern: '^_' }]`).
- **No `console.log`** in production code. `console.error` and `console.warn` are permitted for operational logging only.
- **Server actions** use `FormData` + Zod validation. `revalidatePath()` and `redirect()` guarded by `NODE_ENV !== 'test'`.
- **Edge runtime** for API routes — webpack config in `next.config.ts` excludes Node DB modules on edge.
